# BugHunter Pass 3 — Authorized BugFix

Use the existing approval and Pass workflow to repair a coherent batch of
confirmed, eligible findings. User mode investigates and reports findings. In
Dev mode, the authenticated user can grant or revoke standing authority for a
repository, branch, remedy classes, actions, and paths. Explicit prohibitions
override standing authorization.

BugFix confirms that the defect remains on the authorized target before
starting a source Task. The shared Pass uses one worktree and draft PR with
conditional resumption, verified changes, and an independent review for the
exact candidate tree. Keep pending Git and GitHub operations for reconciliation
before retry. Release execution capacity after a safe pause, failure, or budget
stop while preserving the same Pass and its checkout.

Keep deferred architecture out of repair Tasks. Report implementation,
verification, integration, installation, and operational recovery separately.
An operational recovery claim requires a verified exercise of the formerly
failing behavior on the repaired running build.

Extend the existing Traditional Tests, verify the local combined suite and
run the existing model-backed route where needed. An unattended merge into a
real target stays gated pending Pass 4 and an authenticated standing grant.
