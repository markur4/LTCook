# Planning

Use the `ltcook-planning` skill during every Design and Plan workflow. Its complete `references/modes.md` file is the authoritative planning strategy; preserve its explicit requirements when applying them.

Use the registered `ltcook planning` operations to start and inspect planning, answer decisions, and approve or reject a Plan. An agent report or Markdown statement is not a user answer or execution approval. Runtime authorization governs tool use and execution; this guidance does not grant permission.
